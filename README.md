# DelayCamera
遅延カメラ

## 実行環境
python 3.14

## 必要なライブラリ
- opencv-python


## つかいかた
```
$ python DelayCam.py
```

## コマンド例(windows)
ps1を実行できるようにするコマンド
```
$ Set-ExecutionPolicy RemoteSigned
```
ライブラリインストール
```
$ python -m venv .venv
$ source .venv\Scripts\Activate.ps1
$ pip install opencv-python
```
実行
```
$ python DelayCam.py
```
